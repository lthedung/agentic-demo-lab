# Coffee Landing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page Next.js landing page using Tailwind CSS to introduce a premium coffee brand.

**Architecture:** Scaffold a Next.js App Router application in the repository root and implement the landing page as focused React components. The page is static, with product/process content stored in local arrays and styled with Tailwind utility classes inspired by `DESIGN.md`.

**Tech Stack:** Next.js, React, TypeScript, Tailwind CSS, ESLint, Playwright/manual browser verification.

---
